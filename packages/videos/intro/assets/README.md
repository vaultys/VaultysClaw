# Brand assets

- `vaultys.svg` — the Vaultys shield (from VaultysHub), recoloured white by `intro/render.ts`.
- `claw-shield.png` — the VaultysClaw shield, orange `#D35400` (interior transparent); `claw-shield-white.png`, the same in white.
- `claw-wordmark.png` — the VaultysClaw wordmark as supplied: orange shield and "CLAW", navy `#16323D` "VAULTYS".
  - `claw-wordmark-light.png` — "VAULTYS" in white, for the marketing video's navy backdrop.
  - `claw-wordmark-white.png` — all white, for the intro/outro's orange scene.

The variants are derived from the two originals by recolouring opaque pixels (navy → white, or everything → white).
